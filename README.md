# Anything Kart

A kart racer where **whatever you're holding becomes your steering wheel**. Pick up a plate, a book or a TV remote, hold it up to your webcam, and turn it like a wheel to race original helmeted drivers across a sunny coast, a snowy pass and a twisty canyon. No object handy? Just hold your hands up as if gripping a wheel.

Everything runs in the browser on the player's own device. Camera video is never uploaded, and there are no accounts or API keys.

## Getting started

Requirements: Python 3 (preinstalled on macOS) and a modern browser (Chrome, Edge, Safari or Firefox).

```bash
npm start
```

or, without Node:

```bash
python3 scripts/serve.py
```

Then open the address it prints. On macOS you can also double-click `scripts/start.command` (the first time, right-click it and choose Open).

The game needs a small local server because browsers only allow the camera on `http://localhost` or `https://` pages. Phones need the game on a real `https://` site.

## How to play

In **Race setup**, choose your racer, mode, track and bot skill. Camera players then press **Next: lock on** and allow the camera.

**Lock on** (a few seconds, before each race):

1. Hold your object (or just your hands) up with both hands, a little apart. A ring appears between them.
2. **Get comfortable**, then **hold steady** for a second while the green arc fills: that becomes straight ahead.
3. **Turn left, then turn right** as the banner asks. How far you turn sets your steering range.
4. **Raise it and hold** for about 1.5 s to start (or press **Start race** / Space).

In the race, **turn to steer** and **flick it** to use your item: a quick snap of your wrists, a quick pop up, or a quick jab toward the screen. The kart accelerates by itself.

Your lock-on lasts the whole race. If a hand is hidden for a moment, steering carries on from the other hand; if both hands leave, the race pauses and carries on when they're back.

### Controls

| Action | Camera | WASD | Arrows | Gamepad |
|---|---|---|---|---|
| Drive | automatic | W / S | Up / Down | A (or RT) / B |
| Steer | turn it | A / D | Left / Right | left stick |
| Drift | automatic (if Auto drift is on) | Space | Right Shift | RB |
| Item | flick it (backup key: X for P1, N for P2) | E | Enter | LB or X |

Keys: `Esc` pause · `F` full screen · `M` mute · `C` camera view · `R` recenter steering · `D` diagnostics.

### Players

Up to 4 players. Up to **2 can share the camera**, standing side by side (P1 on the left, P2 on the right); everyone else uses a keyboard (WASD or arrows) or a gamepad.

### Settings

**Steering options** (lock-on screen): steer by (turning, moving, or both), full-turn angle, dead zone, sensitivity, fine control near the middle, flick sensitivity (Light / Normal / Firm), auto drift (off by default), lower it to brake (off by default), reverse steering, and "my camera already mirrors the picture".

## Game content

- **Tracks:** Sunny Coast (easy), Snowpeak Pass (medium), Canyon Wiggle (hard, with precision gates).
- **Modes:** Race, Time Trial, Acorn Rush, Knockout.
- **Bot skill:** Beginner, Easy, Normal, Hard (speed, cornering, steering, catch-up and item use all differ).
- **Items:** Hot Chili (boost), Chili Pack, Mud Pie, Snowball, Busy Bee (homing), Bubble Shield, Acorn Bag.

All art, characters, tracks, music and sound effects are generated by the game's own code; there are no image or audio files.

### How the steering works (`src/steering/`)

The race only reads each camera player's output and never touches the camera code:

```
{ steering: -1..1, item, brake, verticalPosition, confidence,
  trackingState: tracking | degraded | temporarily_lost | reacquiring | paused,
  activeSignals: { leftHand, rightHand } }
```

| File | Job |
|---|---|
| `engine.js` | One per camera player: lock-on, the per-frame pipeline, the output, the ring's pose |
| `config.js` | The output shape, tracking states and every tunable number |
| `hands-pose.js` | Keeps following the same two hands and which is left and right |
| `snap.js` | Spots quick snaps in a signal (used for flicks) |
| `state.js` | The tracking state machine and its timeouts |
| `filters.js` | One-euro filter, smoothing and rate limits |
| `overlay.js` | Drawing the ring, hand landmarks and the in-race status strip |

- **Angle:** the line between the two palm centres compared with the lock-on angle, then a one-euro filter, dead zone, the player's range, a response curve and a rate limit.
- **One hand hidden:** while both hands are visible the game learns how each sits on the object; when one is hidden for up to 3 s, the other hand's tilt gives the angle, cross-checked against its position.
- **Flicks:** a fast movement both hands share, far enough, then stopping: the palms' midpoint popping up, the palms foreshortening (a wrist snap), or their spacing growing (a jab).
- **Identity:** only the original pair of hands is followed; impossible jumps are thrown away.

## Testing

No webcam needed: open `http://localhost:8000/?fakecam` for a simulated camera (`?fakecam=2` for two players). Then, in the browser console:

```js
await (await import('/tests/brief.js')).brief()                   // steering and flick checks, one line each
await (await import('/tests/brief.js')).brief({ obj: 'book' })    // with a prop drawn in the hands
await (await import('/tests/brief.js')).brief({ mirrored: true }) // a camera that mirrors the picture
await (await import('/tests/handling.js')).run()                // how much a camera-steered kart slides
```

Reload the page between runs.

## Privacy

The camera picture is processed on the device and never leaves it. Settings are stored in the browser's local storage.
